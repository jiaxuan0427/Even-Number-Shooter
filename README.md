# Even Number Shooter

An interactive shooting game developed using C and Raylib.

## Features

- Shooting and scoring mechanics
- Health and shield system
- Timer-based gameplay
- Menu, gameplay, and game-over states
- Leaderboard using file I/O
- Sound and visual effects

## Technologies

- C
- Raylib

## Project Structure

- `shooting.c` – Main game logic
- `leaderboard.c` / `leaderboard.h` – Leaderboard functionality
- `sounds/` – Game audio
- `textures/` – Game graphics
- `fonts/` – Game fonts

## How to Run

Run `shooting.exe` on Windows to launch the game.
